# Cheatsheet — pedagogia-cognitiva

## Reglas de decisión rápida

| Situación | Hacer | Por qué (fuente) |
|---|---|---|
| Lector nuevo en un tema | Diagnosticar conocimiento previo vía perfil (dim. 6) antes de asumir nivel | HLW Ch1, WDSL Ch2 |
| Al presentar contenido nuevo | Exponer explícitamente las conexiones entre conceptos, no solo listarlos | HLW Ch2 |
| Al abrir un tema (motivación) | Anclar en algo relevante al perfil específico (valor subjetivo) + primera victoria alcanzable (expectativa de éxito) | HLW Ch3 |
| Habilidad compleja con sub-partes | Enseñar componentes → practicar integración → exponer cuándo aplicar cada uno (3 pasos, no 1) | HLW Ch4, WDSL Ch5 |
| Diseñar cualquier ejercicio | Objetivo específico + dificultad calibrada al desempeño actual + cantidad suficiente | HLW Ch5, WDSL Ch1 |
| Redactar sección de errores | Discrepancia objetiva, nunca juicio de valor | HLW Ch6 |
| Cerrar un bloque teórico | Micro-chequeo inmediato después, no al final del documento | HLW Ch7, MIS Ch2 |
| Ejemplo resuelto para novato en ESE tema | Andamiaje completo, todos los pasos explícitos | HLW Ch4, CLT Parte II, 2.1.3 |
| Ejemplo resuelto para experto en ESE tema | Fading + generación: problema antes que explicación | HLW Ch4/Ch7, MIS Ch4, CLT Parte II, 2.1.3 |
| Primer bloque de ejercicios de un tema nuevo | 100% blocked practice, sin intercalar todavía | MIS Ch3, CLT Parte II |
| Ejercicios de un tema ya asimilado | Intercalar con temas previos de la MISMA familia | MIS Ch3, Ch5 (Goldstone) |
| Verificar un ejercicio con resultado calculable | Chequeo independiente (script), nunca solo juicio propio del texto generado | MIS Ch5, WDSL Ch9 |
| Usar una metáfora/mnemotécnico de apoyo | Retirarla progresivamente una vez el tema se automatiza | MIS Ch7 |
| Decidir qué "estilo" de presentación usar | Variar el modo (ejemplos + estructura), no encasillar por preferencia fija | MIS Ch6, WDSL Ch7 (confirmado por 2 fuentes) |
| Texto + diagrama que deben integrarse | Colocarlos juntos en espacio y tiempo | CLT Parte III-A (split-attention effect) |
| Fórmula o notación densa | NO exceptuar del minimalismo — nada de adorno alrededor | CLT Parte III-A (redundancy effect) |
| Ejemplo resuelto en el texto | Pedir autoexplicación explícita, no dejarlo como lectura pasiva | CLT Parte III-B |
| Ejercicio para entrenar patrón, no solo resultado | Considerar meta abierta en vez de fija ("encontrá todo lo que puedas") | CLT Parte III-B (goal-free effect) |
| Concepto abstracto nuevo | Presentar 2+ ejemplos de distinta superficie, misma estructura profunda | WDSL Ch4, MIS Ch6 |
| Comunicar una dificultad o error | Enmarcar como proceso en desarrollo, nunca como techo de capacidad fijo | WDSL Ch8, MIS Ch7 |

## Umbrales y valores de referencia
- Feedback punitivo → activa amenaza percibida → consume recursos cognitivos que deberían ir al contenido (no es "más estricto = más riguroso", es directamente contraproducente).
- Ilusión de competencia/de saber: mayor cuanto más pasiva es la lectura — el antídoto es siempre testing activo bajo condiciones realistas, no relectura ni juicio subjetivo (confirmado por HLW Ch7, MIS Ch5).
- Ceguera del experto: cuanto más domina el redactor (o la fuente) un tema, más riesgo de saltear pasos que para un novato NO son obvios.
- Interleaving sin blocked practice previo = frustración sin beneficio — el orden importa, no solo la mezcla final.
- Generación (problema antes que explicación) solo rinde después del umbral de expertise en ESE tema — antes del umbral, genera solo frustración (confirmado formalmente como "expertise-reversal effect", CLT Parte II).
- El expertise-reversal effect es siempre de (sub)dominio específico, nunca global — la misma persona puede estar antes del umbral en un tema y después en otro.
- Split-attention aplica también en el tiempo, no solo en el espacio — una narración desincronizada con lo que se muestra en pantalla también induce carga extraña.

## Tells / señales de alerta al redactar
- Si una sección de "errores comunes" suena a regaño → violación directa de HLW Ch6 + regla de tono 2.1.1-1, y reduce persistencia futura medible (WDSL Ch8).
- Si el ejemplo resuelto tiene el mismo nivel de detalle sin importar el tema → falta de calibración por perfil (HLW Ch1+Ch4, CLT Parte II).
- Si el "chequeo de comprensión" es uno solo al final del documento → contradice HLW Ch5/Ch7 y MIS Ch2 (feedback oportuno, combate a la ilusión de competencia/saber).
- Si los ejercicios intercalados aparecen desde el primer bloque de un tema nuevo → contradice MIS Ch3 (falta blocked practice previo).
- Si una metáfora se sigue repitiendo sin cambios en temas donde el perfil ya indica dominio → contradice MIS Ch7 (andamiaje no retirado).
- Si un diagrama y su texto explicativo quedan en secciones separadas del documento → contradice CLT Parte III-A (split-attention).
- Si se agrega una aclaración o nota "por las dudas" que no aporta información nueva → contradice CLT Parte III-A (redundancy effect).
- Si un concepto abstracto se presenta con un solo ejemplo → riesgo de que el lector memorice la superficie sin extraer la estructura profunda (WDSL Ch4).
